# النسخة السابقة (v5.7.1)

واجهة Tkinter التي حلّت محلّها واجهة الويب في v7.0.

محفوظة هنا لأن محرّكها هو أصل الوحدات في `taxi/` — نُقل المنطق كما هو
دون إعادة كتابة. تبقى صالحة للتشغيل إن احتجتها:

```
cd legacy
python taxi_pro.py
```

| الملف | ماذا كان |
|---|---|
| `taxi_pro.py` | البرنامج كاملاً — المحرّك والواجهة في ملف واحد (4400 سطر) |
| `taxi_agent.py` · `taxi_agent_gui.py` | وكيل معالجة الدُفعات |
| `run.bat` · `تشغيل_offline.bat` · `تشغيل الوكيل.bat` | مُشغّلات Windows |

ما في `taxi_pro.py` ولا مقابل له في v7: لا شيء — نُقلت كل المزوّدين
والفحوصات. وما في v7 ولا مقابل له هنا: واجهة الويب، البحث في السجلّات،
المراجعة إلى جانب الصورة الأصلية.
